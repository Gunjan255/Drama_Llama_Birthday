
# Drama Llama — Birthday Surprise ❤️

A mainstream, cinematic romantic birthday website built with Python + Flask.

## Run it

```bash
cd Drama_Llama_Birthday
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open:

http://127.0.0.1:5000

## Customize

- Change text in `app.py` or `templates/index.html`.
- Replace the four files inside `static/images/` if you want different photos.
- Change `SONG_URL` in `app.py` if you have a preferred official music page.
- The site does not bundle copyrighted music; the VALLAH button opens a YouTube search.

## Theme

The experience intentionally feels like a normal romantic microsite rather than a programming demo.
There is one subtle developer Easter egg near the end: "Built with Python. Powered by love."
